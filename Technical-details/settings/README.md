# Apply exact saved settings

With REAPER closed, copy the desired file to the root of a fresh 7.83 resource directory. On an established profile, copying replaces all records in that file. Install the scripts, custom theme, icons and extensions referenced by the files before verifying in REAPER.

| File | Location in REAPER |
| --- | --- |
| reaper-kb.ini | Actions → Show action list |
| reaper-mouse.ini | Preferences → Editing Behavior → Mouse Modifiers |
| reaper-menu.ini | Customize menus/toolbars |
| reaper-screensets.ini | View → Screensets/Layouts |
| reaper-themeconfig.ini | Theme adjuster |
| libSwell.colortheme | Linux native controls |
| libSwell-user.colortheme | Linux native controls · user override |
