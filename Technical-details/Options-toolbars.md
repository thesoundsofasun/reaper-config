# Options → Customize menus/toolbars

Right-click a toolbar → **Customize toolbar**. Select the toolbar, then insert each command or separator in the order below. The stored slot numbering starts at zero. Restore Data/toolbar_icons before selecting custom icons. The first-run archive has no saved toolbar customization file.
