# Setting differences

37,275 differing records across current configuration, theme definitions, presets, scans and browser state. Added 36,609 · Changed 662 · Removed 4. INI sections and keys are compared case-insensitively, with repeated keys tracked by occurrence. JSON arrays retain order. Plain non-key records in INI files retain their sequence. Action registrations and bindings have a dedicated chapter. Historical backup files are in the file manifest.

Values that contain long payloads are represented by length and fingerprint. Private registration values and browsing history are withheld. A first launch writes a sparse INI. An added entry can store the same value REAPER already used internally.
